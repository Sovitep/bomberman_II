A Bomberman-style grid-based action game built in **Godot 4.5**.  
Focus: player movement, bomb placement, explosions, and classic arcade mechanics.

1. Story
Bomberman was framed robbing the bank, now he tries to escape the  jail and bring the real criminal to justice
