 
# Bomberman II
 
## Overview
Bomberman is a 2D top-down arcade game developed as part of an academic game project. Inspired by the classic Bomberman franchise, the game features grid-based movement, strategic bomb placement, destructible environments, and power-up systems all in a pixel-art style built with Godot Engine. 

Bomberman was living a quiet life until one day he when he met an incident where he was framed for robbing the city bank. With no evidence to prove his innocence, he was sentenced and thrown behind bars. Right now he tried to breakout of prison and find the real criminal and put it to justice.
